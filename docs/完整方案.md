## 1. 产品定位

**一句话**：本地优先的「知识库 + 内置浏览器工作台」，边浏览 AI/常用站边划词入库，也能从外部浏览器右键快录，支持语义搜索与全文浏览。

**不是**：又一个多模型聊天客户端（Cherry / Chatbox 赛道）。  
**是**：个人第二大脑的「采集入口 + 检索柜 + 常驻工作页签」。

### 1.1 核心用户故事

1. 打开应用：左侧管知识，右侧像浏览器一样开着 ChatGPT / Grok / Gemini…
2. 页签内选中文字 → 右键「存入知识库」；若右键不可用 → 复制后快捷键入库（兜底）。
3. 系统 Chrome 里划词，扩展右键同样入库（P1）。
4. 浏览全部知识、按标签/来源筛选；语义搜索「上次关于某某的那段」。
5. 地址栏粘贴 URL 打开；预置站点一键开标签；后台标签可休眠省内存。

## 2. 范围与非目标

### 2.1 MVP 必做（P0）

| 模块 | 能力 |
|------|------|
| 知识录入 | 手动粘贴；应用内右键快录；**复制 + 全局快捷键入库（兜底）** |
| 向量化 | 异步切块 + embedding；pending/processing/done/failed；失败可重试 |
| 搜索 | 向量 + FTS5 混合（RRF）；**无 Key 时明显降级为仅 FTS** |
| 浏览 | 全部条目列表/详情；删除、编辑标签 |
| 页签浏览器 | 多标签、导航、地址栏、预置书签；**后台标签休眠** |
| 预置站 | ChatGPT、Grok、Gemini、Google、X、Telegram Web（可配置） |
| 本地存储 | 单机 SQLite，数据在用户目录 |

### 2.2 P1

- Chrome/Edge 扩展右键入库  
- 文件夹/多知识库  
- Markdown/TXT 单文件导入、多知识库（打包导入导出已升为 **M3/MVP 必做**，见技术评审）  

### 2.3 非目标（首版不做）

- 云同步、团队协作、权限  
- 完整 Agent / MCP 市场 / 多模型聊天主界面  
- 替代系统默认浏览器  
- 移动端

## 3. 信息架构与界面

```
┌──────────────┬────────────────────────────────────────┐
│ 侧栏         │ 顶栏：标签条 + 地址栏 + 导航按钮         │
│ · 知识库     │────────────────────────────────────────│
│ · 搜索       │                                        │
│ · 全部知识   │     WebContentsView（当前标签页）        │

│ · 设置       │                                        │

```

**入库路径（必须三条都通，至少两条在 MVP）：**

1. 右键「存入知识库」（应用内 WebContents）  
2. `Ctrl+Shift+S`（可配置）：读取剪贴板 → 入库弹窗（**X/TG 等右键失败时的官方兜底**）  
3. P1 扩展右键 → Local API  

设置/搜索页在未配置 embedding 时展示固定横幅：  
「向量检索未启用，当前仅关键词搜索；配置嵌入模型后自动补齐向量。」

```
┌───────────────▼─────────┐  ┌────────▼────────────────────────┐
│ Renderer (React)        │  │ WebContents 标签                 │
│  知识 / 搜索 / 设置      │  │  contextMenu + clip 兜底快捷键   │
└─────────────────────────┘  └─────────────────────────────────┘
                │
       ┌────────▼────────┐
       │ SQLite + FTS5   │
       │ Vector backend  │
       └─────────────────┘
```

### 4.1 标签休眠策略（硬性）

| 规则 | 默认 |
|------|------|
| 最大「唤醒」WebContents 数 | 6（可设置 4–10） |
| 休眠条件 | 非当前标签，且超过 5 分钟未激活；或超过上限时 LRU 休眠 |
| 休眠时 | destroy WebContents，**保留** url/title/favicon（休眠会重新 load，页内未提交输入会丢；钉选标签默认不休眠） |
| 唤醒时 | 新建 WebContentsView，loadURL；session 仍用 `persist:workbench` |
| 钉选标签 | 可不参与自动休眠（预置常用站可钉） |

### 4.2 划词兼容策略

| 环境 | 主路径 | 失败时 |
|------|--------|--------|
| 普通文档站 | contextMenu 取 `selection` | 快捷键剪贴板 |
| ChatGPT/Gemini | 同上 | 同上 |
| X / Telegram Web | 尽量右键；**不保证** | **产品文案引导：选中→复制→Ctrl+Shift+S** |
| 系统其它浏览器 | P1 扩展 | 同快捷键（应用在后台时） |

## 5. 数据模型与 SQL

见同目录 `schema.sql`（权威）。要点：

- `knowledge_items.embed_status`：pending/processing/done/failed/skipped_no_key  
- 切块按 **估算 token**（中文 ≈ 字数，英文 ≈ 按空白分词×1.3），目标 400–600 tokens，overlap 60–80  
- 向量后端抽象：`vector_meta.backend = sqlite-vec | lance`

## 9. 关键流程

### 9.1 入库（统一）

所有入口最终调用 `ingestService.createFromClip({ text, url?, title?, source_type })` → insert item → enqueue job。

### 9.2 Embedding 未配置

- 仍保存原文与 FTS 索引  
- `embed_status = skipped_no_key`  
- 配置 Key 后提供「补齐全部待向量化」按钮  

### 9.3 本地 API（P1，MVP 可先打通端口供自测）

- 监听 `127.0.0.1`，**端口启动时随机**（写入本地配置供扩展读取）  
- `Authorization: Bearer <token>`  
- 可选：每次启动轮换 token（扩展需重新配对一次）  

### 9.4 导入 / 导出（换机迁移）

**目标**：在公司机与个人机之间搬知识库；可备份；不依赖云同步。

#### 导出格式 `knowledge-backup-v1`

单个 `.zip`（或 `.kbag` 实为 zip）：

```
manifest.json          # version, exported_at, app_version, item_count, embedding_model, vector_dim, backend
items.jsonl            # 每行一条 knowledge_items（不含密钥）
chunks.jsonl           # 可选：已切块，便于免再切
embeddings.jsonl       # 可选：每行 {chunk_id, vector}（dim 一致才可直接用）
attachments/           # 预留
README.txt             # 给人看的说明
```

`manifest.json` 关键字段：`format: "knowledge-backup-v1"`、`embedding_model`、`vector_dim`。

#### 导出选项（UI）

1. **完整包（推荐换机）**：条目 + 切块 + 向量（若有）+ 书签  
2. **仅原文**：条目 + 书签（到新机器后按本地模型重新向量化）  
3. **不含 API Key**：设置里的密钥**永不写入**导出包  

#### 导入行为

1. 选择 zip → 校验 `format` 与版本  
2. 冲突策略：`skip` / `overwrite` / `新建副本（id 重新生成）`  
3. 若导出含向量且 **模型与 dim 与当前设置一致** → 可直接写入向量后端  
4. 若不一致或仅原文包 → 导入正文后批量 `embed_status=pending`，走补齐队列  
5. 导入书签：按 URL 去重合并  

#### 验收

- 机器 A 导出完整包 → 机器 B 导入 → 条目数一致，搜索可用（同模型）或补齐向量后可用  
- 导出文件可复制到 U 盘 / 网盘手动传输

## 12. 验收标准（MVP 修订）

1. 录入后向量化成功（有 Key）；无 Key 时条目可 FTS 搜到且横幅可见  
2. 语义或关键词能命中  
3. ≥6 预置站；粘贴 URL；超过上限后后台标签休眠，点开可恢复  
4. 应用内右键入库 **或** 复制+快捷键入库，至少一种在 X/TG 场景可用  
5. 重启后知识/书签/标签 URL 恢复  
6. 向量失败可一键重试  
7. **导出 zip 不含 API Key；另一台机器可导入并恢复条目（向量同模型可复用，否则可重建）**
